ตรวจสอบรายชื่อซัพพลายเออร์

วางรายชื่อของคุณ แล้วระบบจะบอกว่าชื่อไหนตรงกับข้อมูลของเรา

🔒 ข้อมูลเป็นความลับทั้งสองฝ่าย

  • ต้องใช้ รหัสเข้าใช้ จากผู้ดูแล — คนนอกที่เจอลิงก์ใช้ไม่ได้
  • หน้านี้ ไม่แสดงและไม่ดาวน์โหลด รายชื่อของเรามาที่เครื่องคุณ — คุณจะเห็นแค่ผลว่าบรรทัดของคุณ “ตรง / ใกล้เคียง / ไม่พบ”
  • รายชื่อที่คุณวาง ไม่ถูกบันทึก ที่ใดเลย ใช้เทียบแล้วทิ้งทันที เราไม่เห็นว่าคุณพิมพ์อะไร
  • กด “ล้างข้อมูล” เพื่อลบทุกอย่างออกจากหน้าจอ (ปิดหน้าเว็บก็หายเช่นกัน)

วิธีใช้

  1. 1 บรรทัด = 1 ซัพ — ใส่ชื่อภาษาไทยหรืออังกฤษก็ได้
  2. ก็อปรายชื่อจาก Excel / Google Sheet (คอลัมน์เดียว) มาวางในกล่องได้ทั้งหมดทีเดียว
  3. ไม่ต้องใส่ “บริษัท / จำกัด / Co., Ltd.” ก็ได้ และพิมพ์ผิดเล็กน้อยระบบยังจับได้
  4. กด “ตรวจสอบ” ผลจะขึ้นเป็นสีตามด้านล่าง
0 รายชื่อสูงสุดครั้งละ 2,000 บรรทัด

ผลการตรวจสอบ

🟩 ตรงกัน = มีข้อมูลตรงกับของเรา  ·  🟨 ใกล้เคียง = คล้ายมาก โปรดตรวจตัวสะกดอีกครั้ง  ·  🟥 ไม่พบ = ไม่มีในข้อมูลของเรา
