# ตรวจสอบรายชื่อซัพพลายเออร์ (Supplier Match Checker)

โปรแกรมเช็คว่ารายชื่อซัพของ "ผู้ตรวจ" ตรงกับรายชื่อของ "เรา" หรือไม่ โดย **ทั้งสองฝ่ายไม่เห็นข้อมูลของกันและกัน**

```
 ฝั่งผู้ตรวจ                          ฝั่งเรา (ส่วนตัว)
 ┌──────────────────┐   ส่งรายชื่อ   ┌──────────────────────┐   อ่าน   ┌──────────────┐
 │ หน้าเว็บ GitHub   │ ─────────────▶ │ Google Apps Script    │ ───────▶ │ Google Sheet │
 │ (index.html)      │ ◀───────────── │ (เทียบชื่อ ไม่บันทึก)  │          │ (ไม่แชร์)     │
 └──────────────────┘  ตอบแค่ ตรง/   └──────────────────────┘          └──────────────┘
                        ใกล้เคียง/ไม่พบ
```

- Google Sheet ของเรา **ไม่ต้องแชร์ ไม่ต้อง Publish** — มีแค่สคริปต์ที่อ่านได้
- หน้าเว็บได้รับแค่ผลของแต่ละบรรทัด ไม่เคยได้รับรายชื่อในชีท
- สคริปต์ไม่บันทึกสิ่งที่ผู้ตรวจส่งมา

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บให้ผู้ตรวจใช้ (ขึ้น GitHub Pages) |
| `config.js` | ใส่ URL ของ Apps Script |
| `apps-script/Code.gs` | โค้ดฝั่งเรา วางใน Google Sheet |

---

## ส่วนที่ 1 — ตั้งค่าฝั่งเรา (Google Sheet) ทำครั้งเดียว

1. สร้าง Google Sheet ใส่ข้อมูลแบบนี้ (แถว 1 เป็นหัวตาราง)

   | A: ลำดับ | B: ชื่อซัพ (ไทย) | C: ชื่อซัพ (อังกฤษ) |
   |---|---|---|
   | 1 | บริษัท เอบีซี เทรดดิ้ง จำกัด | ABC Trading Co., Ltd. |
   | 2 | หจก. สมชายการช่าง | Somchai Engineering Ltd., Part. |

   ช่องไหนไม่มีชื่อปล่อยว่างได้
2. เมนู **Extensions (ส่วนขยาย) > Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs` → กด 💾 Save
4. (ทดสอบ) เลือกฟังก์ชัน `testMatch` แล้วกด **Run** → อนุญาตสิทธิ์ครั้งแรก → ดูผลใน Execution log
5. **ตั้งรหัสเข้าใช้** (สำคัญ — ไม่ตั้ง = ระบบปฏิเสธทุกคำขอ)
   - ⚙️ **การตั้งค่าโปรเจ็กต์ (Project Settings)** > เลื่อนลงไปที่ **พร็อพเพอร์ตีของสคริปต์ (Script Properties)** > **เพิ่มพร็อพเพอร์ตีของสคริปต์**
   - พร็อพเพอร์ตี: `ACCESS_CODE` · ค่า: รหัสที่จะให้ผู้ตรวจ (ตั้งให้เดายาก เช่น 8 ตัวขึ้นไป)
   - กด **บันทึก** — รหัสอยู่ใน Google เท่านั้น ไม่อยู่ในโค้ด ไม่ขึ้น GitHub
   - เปลี่ยนรหัสเมื่อไรก็ได้ที่เดิม มีผลทันที ไม่ต้อง Deploy ใหม่
6. กด **Deploy > New deployment**
   - ⚙️ Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
7. เปิดไฟล์ `config.js` แล้ววาง URL:
   ```js
   window.CHECKER_API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```

หลังจากนี้ แค่ **เพิ่ม/แก้ชื่อใน Google Sheet** ได้เลย ผลจะอัปเดตทันที ไม่ต้อง Deploy ใหม่
(ต้อง Deploy ใหม่เฉพาะตอนแก้โค้ด `Code.gs` — ใช้ **Deploy > Manage deployments > ✏️ > Version: New version** เพื่อให้ URL เดิมยังใช้ได้)

### ปรับแต่ง (บนสุดของ Code.gs)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `SHEET_NAME` | `''` | ชื่อแท็บ (ว่าง = แท็บแรก) |
| `COL_TH`, `COL_EN` | 2, 3 | คอลัมน์ชื่อไทย/อังกฤษ |
| `MATCH_SCORE` | 0.90 | ความเหมือนขั้นต่ำที่นับว่า "ตรงกัน" |
| `NEAR_SCORE` | 0.80 | ความเหมือนขั้นต่ำที่นับว่า "ใกล้เคียง" |

## ส่วนที่ 2 — ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (Public)
2. อัปโหลด `index.html`, `config.js` (และ `README.md`, `apps-script/` ได้ เพื่อให้ผู้ตรวจเห็นว่าโค้ดไม่ได้เก็บข้อมูล)
   > ⚠️ **ห้ามอัปโหลดไฟล์ข้อมูลรายชื่อ** ขึ้น GitHub
3. **Settings > Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` → ส่งให้ผู้ตรวจ

## ส่วนที่ 3 — วิธีใช้ (สำหรับผู้ตรวจ)

1. เปิดลิงก์ที่ได้รับ แล้วใส่ **รหัสเข้าใช้** ที่ได้จากผู้ดูแล
2. ใส่รายชื่อ **1 บรรทัด = 1 ซัพ** (ไทยหรืออังกฤษก็ได้)
   - พิมพ์ทีละชื่อแล้วกด **เพิ่ม** หรือ
   - ก็อปจาก Excel/Google Sheet (คอลัมน์เดียว) วางลงกล่องใหญ่ทีเดียว
3. กด **ตรวจสอบ**
   - 🟩 **✓ ➜ ตรงกัน** — มีในข้อมูลของเรา
   - 🟨 **≈ ใกล้เคียง** — คล้ายมาก (พิมพ์ผิด / ชื่อไม่ครบ) โปรดตรวจอีกครั้ง
   - 🟥 **✗ ไม่พบ** — ไม่มีในข้อมูลของเรา
4. กดป้ายสรุปด้านบน (ตรงกัน / ใกล้เคียง / ไม่พบ) เพื่อกรองดูเฉพาะกลุ่ม
5. กด **ล้างข้อมูล** เมื่อเสร็จ

## ระบบจับคู่ทำงานอย่างไร

1. ตัดคำที่ไม่ใช่ชื่อจริงออก: บริษัท, จำกัด, (มหาชน), บจก., หจก., Co., Ltd., Limited, Inc., PCL ฯลฯ
2. ตัวพิมพ์เล็ก-ใหญ่ เว้นวรรค จุด ขีด วงเล็บ ไม่มีผล
3. เทียบกับทั้งชื่อไทยและชื่ออังกฤษในชีท
4. ยอมให้พิมพ์ผิด/ตกหล่นได้เล็กน้อย (วัดด้วยความเหมือนของตัวอักษร)
5. ชื่อที่พิมพ์มาไม่ครบ (เป็นส่วนหนึ่งของชื่อเต็ม) จะขึ้นเป็น "ใกล้เคียง"

ข้อจำกัด: ระบบเทียบ "ตัวอักษร" จึงจับคู่ **ชื่อไทย ↔ ชื่ออังกฤษที่สะกดคนละภาษา** ไม่ได้ (เช่น พิมพ์ "เอบีซี" จะไม่ตรงกับ "ABC") — ดังนั้นควรกรอกทั้งชื่อไทยและอังกฤษในชีทของเรา

## หมายเหตุเรื่องความเป็นส่วนตัว

- ผู้ตรวจจะรู้แค่ว่าชื่อที่ **เขาพิมพ์เอง** มีในข้อมูลเราหรือไม่ — ไม่เห็นชื่ออื่นในชีท
- เราไม่เห็นสิ่งที่ผู้ตรวจพิมพ์ เพราะโค้ดไม่บันทึกไว้ (ตรวจสอบได้จาก `Code.gs` ที่เปิดเผยบน GitHub)
- ต้องมี **รหัสเข้าใช้** ถึงจะตรวจได้ ใส่ผิดเกิน 10 ครั้ง ระบบล็อก 15 นาที — กันคนนอกที่เจอลิงก์สุ่มเดาชื่อ
- ผู้ตรวจที่มีรหัส ยังเดาชื่อทีละชื่อได้ (เป็นธรรมชาติของระบบเช็ค) — ให้รหัสเฉพาะคนที่ไว้ใจ และเปลี่ยนรหัสเมื่อจบงาน
- ถ้าต้องการปิดระบบ: Apps Script > **Deploy > Manage deployments > Archive**
- ถ้า URL หลุดไปที่ไม่ควร: สร้าง deployment ใหม่ = ได้ URL ใหม่ ของเก่าใช้ไม่ได้ทันที
